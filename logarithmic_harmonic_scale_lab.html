Reading the plot

Two dots on different rows at the same horizontal position represent partials with the same frequency. Short vertical connectors mark pairs within the selected cents tolerance. This is a spectral alignment view, not a claim that every alignment is automatically consonant: amplitude, masking, critical bands and musical context still matter.

Mathematical model and limitations
Equal divisions: f(k) = f₀ · 2^(k/N)
Harmonic ratios: c(r) = 1200 · frac(log₂(r))
Partial n: fₙ = n · f₀ · 2^(c/1200)

For the ratio lattice, p/q is reduced before filtering. A prime limit allows only prime factors no larger than the chosen limit; the numerator and denominator are each bounded by the harmonic limit. Ratios are folded modulo the octave and near-identical pitch classes are merged. Because the rational lattice is dense, increasing the limit creates more positions but does not converge to a finite “natural” scale.

The chord presets begin with simple target ratios and snap each target to the nearest available scale degree. The displayed error is the signed cents difference. The audio engine uses additive harmonic synthesis with amplitudes proportional to 1/nᵅ. The spectrum chart uses the same partial count, but coincidence counts are geometric diagnostics, not psychoacoustic consonance scores.

Pitch is represented logarithmically because intervals are frequency ratios. Octave folding uses modulo 1200 cents; the equal-tempered grid is one possible coordinate lattice, while the harmonic ratio scale is nonuniform.

Standalone file: all controls, synthesis, scale generation and WebGL rendering run locally in this browser. Audio requires a user gesture and a browser with Web Audio support.
